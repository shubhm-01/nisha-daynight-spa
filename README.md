# Nisha Daynight Spa

Luxury spa homepage for Nisha Daynight Spa, Chhatrapati Sambhajinagar, Maharashtra.

## Stack
- Static HTML, CSS and JavaScript
- No build step or package installation required
- Google Fonts (Manrope and DM Sans)
- Pexels-hosted hero photography

## Local preview
Open `index.html` in a browser or serve this directory with a static HTTP server.

## Cloudflare Pages
- Framework preset: None
- Build command: leave blank
- Build output directory: `/` (repository root)
- Production branch: `main`
